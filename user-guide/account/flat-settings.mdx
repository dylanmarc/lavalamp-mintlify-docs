Some settings are yours; some belong to the flat and can only be changed by an admin. Whoever created the flat is its admin.

## Timezone

**Settings → Flat timezone**

The single most important setting in the app. It decides:

- When chore rotas change over
- When morning chore notifications arrive (from 9am local)
- When the 5pm due-today nudge goes out
- When reminders fire
- When the daily bonus resets

<Warning>
  Get this right before you set up chores. If it is wrong, every notification in the flat arrives at the wrong time of day, and it will not be obvious that the timezone is why.
</Warning>

Changing it later is fine. Expect one rota period of irregular length as the dates re-anchor.

## Flat name

**Settings → Flat Name.** Cosmetic. Change it whenever.

## Default chore rotation

Set the order flatmates take turns in. New rotating chores use it automatically.

**Apply to all chores** pushes the order onto every rotating chore in the flat at once. This is what you want when someone moves in or out - otherwise you are editing every chore by hand.

<Note>
  Applying the default overwrites the rotation on every rotating chore. If one chore has a deliberately different order, you will need to set it again afterwards.
</Note>

## Invites

| | |
| --- | --- |
| **New link** | Creates an invite link and copies it |
| **Copy short code** | The typeable version |
| **Revoke invite** | Kills that link. People who already joined stay |

You can only copy a link at the moment you create it. FlatApp does not keep the link itself - it keeps only enough to check one when it is used, which is what stops a leak handing out access to your flat. Lost it? Revoke and make a new one.

Revoke a link if you shared it somewhere public, or once everyone has joined.

## Members

**Settings** lists everyone in the flat.

Someone leaves with **Leave Flat** on their own account. They are taken off all rotas, and what they did stays in the flat's history so balances and completion records still make sense.

<Warning>
  Settle up before anyone leaves. Leaving does not clear a balance, and it is much harder to sort out afterwards.
</Warning>

## Admin-only

If you see "Only the flat admin can update flat settings", you are not the admin. Ask whoever created the flat.

Admin-only:

- Flat name and timezone
- Default rotation, and applying it
- Creating and revoking invites

Everyone can add and complete chores, log expenses, use the lists, and create reminders, polls and bounties.
