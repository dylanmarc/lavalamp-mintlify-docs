---
title: "Install the app"
description: "Add FlatApp to your home screen so it behaves like a normal app."
noindex: true
---

FlatApp runs in a browser, but installing it to your home screen is worth the thirty seconds. You get an icon, a full screen without browser chrome, and - this is the important part - **push notifications on iPhone only work once it is installed**.

<Tabs>
  <Tab title="iPhone and iPad">
    <Steps>
      <Step title="Open FlatApp in Safari">
        It has to be Safari. Chrome on iOS cannot install web apps.
      </Step>
      <Step title="Tap Share">
        The square with the arrow, at the bottom of the screen.
      </Step>
      <Step title="Tap Add to Home Screen">
        Scroll down the share sheet to find it.
      </Step>
      <Step title="Tap Add">
        FlatApp appears on your home screen.
      </Step>
      <Step title="Open it from the icon and turn on notifications">
        Notifications will not work if you keep using the Safari tab.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Android">
    <Steps>
      <Step title="Open FlatApp in Chrome">
        You will usually see an **Install app** prompt on your own.
      </Step>
      <Step title="Or use the menu">
        Three dots → **Install app** or **Add to Home screen**.
      </Step>
      <Step title="Confirm">
        Done.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Desktop">
    Chrome and Edge show an install icon in the address bar. Useful if you do a lot of expense entry at a laptop.
  </Tab>
</Tabs>

## Why bother

| | Browser tab | Installed |
| --- | --- | --- |
| Push notifications on iPhone | No | Yes |
| Push notifications on Android | Yes | Yes |
| Home screen icon | No | Yes |
| Full screen | No | Yes |
| Opens without a connection | Partly | Yes |

## Updates

FlatApp updates itself in the background. You never install anything manually. If something looks broken after an update, close the app fully and reopen it.

## Offline

An installed FlatApp opens without a connection, but it cannot show or save data while offline. Anything you type while disconnected is not queued - reconnect and enter it again.

<Warning>
  Do not rely on offline entry for an expense you will otherwise forget. Wait until you have signal.
</Warning>
