Coins are FlatApp's spending currency. They buy reward cases, and cases contain cosmetics for your profile.

## Earning coins

| | Coins |
| --- | --- |
| Easy chore | 10 |
| Medium chore | 25 |
| Hard chore | 50 |
| Easy bounty | 5 |
| Medium bounty | 10 |
| Hard bounty | 15 |
| Daily bonus | 5 to 200 |
| Scrapping a duplicate | 25 to 500 |

Coins are not reduced for being late, unlike XP.

## Cases

A reward case contains one random cosmetic.

| | |
| --- | --- |
| **Buying one** | 100 coins |
| **Winning one** | Occasionally from the daily bonus |

Open them from your profile.

## What is inside

Five rarities:

| Rarity | Chance |
| --- | --- |
| Common | about 46% |
| Uncommon | about 27% |
| Rare | about 14% |
| Epic | about 9% |
| Legendary | about 4.5% |

Cosmetics come in five kinds: **titles**, **avatar colours**, **avatar frames**, **profile effects** and **avatar emoji**. Legendaries include animated frames - galaxy, rainbow, holographic, lightning.

## Duplicates

You will get things you already own. Duplicates go to your inventory, where you can **scrap** them for coins:

| Rarity | Scrap value |
| --- | --- |
| Common | 25 |
| Uncommon | 50 |
| Rare | 100 |
| Epic | 200 |
| Legendary | 500 |

Scrapping a legendary duplicate gets you back five cases' worth of coins, which softens the sting considerably.

<Warning>
  Scrapping is permanent. Check you actually own a second copy before you scrap something you like - if you scrap your only one, it is gone until a case gives you another.
</Warning>

## Equipping

From your inventory, choose what to wear. Five slots, one item each:

| Slot | |
| --- | --- |
| **Title** | Text next to your name |
| **Colour** | Your avatar's background |
| **Frame** | A ring around your avatar |
| **Effect** | An animated flourish on your profile |
| **Emoji** | A small badge on your avatar |

Change it whenever you like. **View Case Contents** shows the whole catalogue, including everything you have not got yet.

## Is it worth it

Cosmetics do nothing except look good. They do not unlock features or change how anything works. They exist because a rota with a small reward attached gets done more often than one without, which is a slightly cynical explanation for a genuinely fun bit of the app.
