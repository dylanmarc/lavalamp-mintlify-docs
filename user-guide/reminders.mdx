Reminders are for dates rather than tasks. Rent, bin night, the inspection, the flatmate's birthday nobody remembers until the day after.

## Adding one

Tap **Add Reminder**.

| Field | |
| --- | --- |
| **Title** | "Rent due", "Bins out", "Inspection" |
| **Date** | When it happens |
| **Time** | What time of day to be told |
| **Repeats** | Daily, weekly, monthly, or once |
| **Notify** | Everyone, or specific people |

## Repeating

| Repeat | Example |
| --- | --- |
| **Daily** | Something during a short intense stretch |
| **Weekly** | Bin night, every Tuesday |
| **Monthly** | Rent, on the first |
| **Same day** | A one-off |

For a weekly reminder you pick the day. For monthly, it repeats on the same date each month.

## Who gets told

By default everyone in the flat. You can narrow it to specific people - rent might go to everyone, while "car service" only concerns whoever owns it.

You need **Reminders** notifications switched on to receive them. That one is on by default.

## Timing

Reminders can arrive up to about fifteen minutes early. That is deliberate: early is useful, late is not.

Times are in your flat's timezone, which an admin sets in **Settings**. If reminders are landing at strange hours, that is what to check.

## Editing

There is no edit. Delete the reminder and add a new one.

## On the dashboard

Upcoming reminders appear on the dashboard, so you see what is coming without going looking.
