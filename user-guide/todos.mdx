Todos are for one-off jobs - chase the landlord, return the router, sort out the internet. Chores repeat and rotate; todos get done once and disappear.

## Adding a task

Type it and add it. Set a priority if it helps:

| Priority | For |
| --- | --- |
| **High** | Deadline, or something is broken |
| **Medium** | Normal |
| **Low** | Whenever |

## Completing

Tick it off. It clears for everyone, and FlatApp records who did it.

**Clear completed** tidies the list. The history is kept separately.

## Lists

Split things up when one list gets unwieldy:

- **Moving in** - bond, utilities, address changes
- **Repairs** - everything the landlord needs to hear about
- **Admin** - bills, contracts, paperwork

Drag to reorder within a list.

## Suggestions

Like the shopping list, FlatApp notices recurring tasks and offers them as suggestions. Pin the ones you always want, dismiss the ones you do not.

## Chore or todo?

<AccordionGroup>
  <Accordion title="Use a chore when">
    It repeats, and it should move between people. Cleaning, bins, bathroom.
  </Accordion>
  <Accordion title="Use a todo when">
    It happens once. Fix the shower, cancel the old broadband, buy a new toaster.
  </Accordion>
  <Accordion title="Use a reminder when">
    It is a date rather than a task. Rent day, bin night, the inspection.
  </Accordion>
</AccordionGroup>
